# Infra

Конфигурация локального окружения и инфраструктурные файлы.

## Содержимое

- `nginx/flowcraft.conf` — базовый конфиг для non-dev запуска frontend через `nginx` с proxy на backend.
- `flowcraft-backend.service` — шаблон systemd-сервиса backend
- `flowcraft-planner.service` — шаблон отдельного фонового планировщика производства

Перед установкой unit-файлов указать фактического системного пользователя и
пути целевой машины. Backend и планировщик использовать с одной конфигурацией
БД. На время резервного копирования SQLite и применения миграций останавливать
оба сервиса.
