# ADR 0001: Базовая структура проекта

## Статус

Accepted

## Контекст

Проект разрабатывается одним человеком и находится на ранней стадии MVP.
Нужна простая структура без микросервисов и лишнего инфраструктурного слоя.

## Решение

- использовать один репозиторий;
- держать backend и frontend в каталоге `apps`;
- отделить продуктовую и доменную документацию в `docs`;
- отложить выделение shared packages до появления реальной необходимости.

## Последствия

- проще поддерживать и развивать MVP;
- ниже порог входа в проект;
- при росте проекта возможна последующая декомпозиция без раннего усложнения.
