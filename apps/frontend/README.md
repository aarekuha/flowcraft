# Frontend

Клиентская часть проекта на `Vue 3 + Vite`.

## Структура

- `src/app` — инициализация приложения, роутер, глобальные стили.
- `src/pages` — экранные маршруты.
- `src/widgets` — крупные блоки экранов.
- `src/features` — пользовательские действия.
- `src/entities` — клиентские доменные представления.
- `src/shared` — общий UI и утилиты.

## Переменные окружения

- `VITE_PUBLIC_APP_URL` — публичный HTTPS-адрес приложения для ссылок в печатных QR-кодах. Если переменная не задана, используется адрес открытого приложения.

Встроенный сканер QR-кодов использует камеру устройства и требует HTTPS, кроме локальной разработки на `localhost`.
