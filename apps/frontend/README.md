# Frontend

Клиентская часть проекта на `Vue 3 + Vite`.

## Структура

- `src/app` — инициализация приложения, роутер, глобальные стили.
- `src/pages` — экранные маршруты.
- `src/widgets` — крупные блоки экранов.
- `src/features` — пользовательские действия.
- `src/entities` — клиентские доменные представления.
- `src/shared` — общий UI и утилиты.
